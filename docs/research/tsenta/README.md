# Tsenta Competitive Research (2026-07-18)

Deep research on Tsenta (tsenta.com, YC S26) — a commercial AI job-application agent
doing sourcing → tailoring → auto-apply → tracking — and a gap analysis against
SmartApplyAI. Input for the improvement/pilot plan.

1. **[01-tsenta-feature-inventory.md](01-tsenta-feature-inventory.md)** — everything the
   product does: sourcing/matching, ATS coverage, tailoring, Q&A, submission automation,
   approval flow, receipts, tracking, 8 surfaces, pricing.
2. **[02-tsenta-methodology-and-tech.md](02-tsenta-methodology-and-tech.md)** — pipeline
   reconstruction (find→prep→apply→track), per-stage methodology, tech-stack evidence
   (autojobs.me infra, cloud workers, MCP), official demo-video transcript findings,
   open unknowns.
3. **[03-tsenta-positioning-ux-market.md](03-tsenta-positioning-ux-market.md)** —
   positioning, onboarding/UX, (near-absent) user feedback, competitor landscape,
   ATS-countermeasure/ethics landscape, business facts.
4. **[04-smartapplyai-current-state.md](04-smartapplyai-current-state.md)** — audited
   module-by-module snapshot of our repo (branch feature/hybrid-filtering); design docs
   are stale, code is ahead; ranked gaps to a daily pilot.
5. **[05-gap-analysis-and-path-forward.md](05-gap-analysis-and-path-forward.md)** — the
   decision doc: capability matrix, root causes of why we're stuck, what to adopt from
   Tsenta (and what not to), priority-ordered workstreams and a pilot definition.
